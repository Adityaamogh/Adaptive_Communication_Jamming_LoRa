# Plots Guide — Before / After Jamming

This file describes the two key plots to include in your report or presentation.

---

## Plot 1 — Packet Loss: Baseline → Jammed → Recovered

Shows the core result of the system. Generated by the Streamlit dashboard (Tab 2).

**How to read it:**
- **Green line (Adaptive LoRa):** Measured loss on the actual link. Spikes during jamming, then drops to 0 % after the AI-triggered hop to 433.75 MHz.
- **Red line (Static LoRa):** Counterfactual — what loss would look like if no hop ever happened (held at the jammed-phase average after the hop time).

**How to export it:**  
In Streamlit, hover over the chart → click the camera icon (📷) in the top-right of the Plotly figure.

---

## Plot 2 — RSSI with ML Classification

Scatter plot from Tab 2 showing the last 60 packets coloured by ML prediction:
- 🟢 Green dots = model predicts Normal
- 🔴 Red dots = model predicts Jammed

This plot demonstrates the classifier working in real time and distinguishes jammed packets (high packet-loss, variable RSSI) from normal ones.

## Plot 3 — Python RF Simulation (for reports only)

Run `model/simulate_jamming.py` to generate:
- `jamming_simulation.png` — LoRa CSS chirp + CW jammer + received signal (SNR collapses)
- `fhss_evasion.png` — Before/after frequency hop (SNR restored on 433.75 MHz)

These are **mathematical simulations** (not hardware recordings) and are useful for the report introduction to illustrate the physics of jamming.

## Suggested Figure Captions

> **Figure 1.** Packet loss (%) over time. The emulated jammer is activated at t ≈ 15 s. After 2 consecutive ML detections, the system autonomously hops to 433.75 MHz at t ≈ 17 s and packet loss returns to 0 %. The red dashed curve shows estimated loss if no adaptive response had occurred.

> **Figure 2.** Real-time RSSI coloured by Random Forest prediction. Green points = model classifies as Normal; red points = Jammed. The classifier correctly identifies jammed packets using packet-loss rate and RSSI variance, not RSSI magnitude alone.
